# Personality and Behavioral Clustering Using Big Five Survey Data

## Project Summary

This project applies unsupervised machine learning techniques to personality survey data using the Big Five personality framework.

The goal was to identify natural personality groupings using clustering methods.

## Methods

- Data cleaning and preprocessing
- Feature scaling
- Principal Component Analysis (PCA)
- K-Means clustering
- Cluster evaluation using elbow method

## Technologies

Python  
Pandas  
NumPy  
Matplotlib  
Scikit-Learn  
Databricks  

## Key Results

- Reduced dimensionality of the dataset using PCA
- Identified personality clusters using K-Means
- Visualized behavioral patterns in personality data

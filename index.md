## 🧠 Personality and Behavioral Clustering Using Big Five Survey Data

This project applies unsupervised machine learning techniques to personality survey data based on the Big Five personality model. The analysis includes data cleaning, feature scaling, Principal Component Analysis (PCA), and K-Means clustering to identify natural personality groupings and behavioral patterns.

**Technologies Used:**  
Python, Pandas, NumPy, Matplotlib, Scikit-Learn, Databricks
